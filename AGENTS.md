separate automated local evidence from owner-reported past device experience.

private source links, credentials, or personal paths to public artifacts.

Input inspection must run before inference submission. Only the capture
controller changes the protection state. Every result carries its source
sequence and protection generation; late results never reopen protection.

limits after every routing and gain operation at both endpoints.

Keep the documented per-buffer capacities, source timing and fixed model
identity. Do not silently change thresholds to make a failed test pass.
